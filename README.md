## Sistema de Recrutamento e Gestão de Vagas

Sistema web desenvolvido para facilitar o processo de divulgação de oportunidades de emprego e recebimento de candidaturas de forma simples, rápida e organizada.

A plataforma permite que empresas divulguem suas vagas e que candidatos encontrem oportunidades disponíveis e realizem suas candidaturas diretamente pelo site, sem a necessidade de criar uma conta.

### Principais funcionalidades

* Divulgação e gerenciamento de vagas de emprego.
* Página individual com informações detalhadas de cada oportunidade.
* Formulário online para candidatura.
* Envio de currículo.
* Organização e gerenciamento de candidatos.
* Área administrativa para acompanhamento das vagas e candidaturas.
* Sistema responsivo para computadores, tablets e celulares.
* Comunicação com candidatos por WhatsApp e e-mail.
* Página de Política de Privacidade e informações relacionadas à proteção de dados.

### Tecnologias utilizadas

* **Next.js**
* **TypeScript**
* **Tailwind CSS**
* **Vercel**
* Banco de dados e armazenamento de arquivos integrado ao sistema.

O projeto foi desenvolvido com foco em **usabilidade, responsividade, organização das informações e facilidade de gestão**, proporcionando uma experiência simples tanto para recrutadores quanto para candidatos.
